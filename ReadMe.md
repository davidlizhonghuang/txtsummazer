# AI Email Assistant

AI Email Assistant is a Streamlit-based web application that uses OpenAI's GPT-3.5-turbo model to summarize email content. Simply paste your email text, and the app will generate a concise summary for you.

## Features

- Paste email content into a text area.
- Generate a summary of the email using AI.
- User-friendly interface powered by Streamlit.
